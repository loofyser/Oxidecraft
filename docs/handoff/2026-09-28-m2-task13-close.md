## How the work runs

One task at a time, in plan order. For each task: extract its text from the plan into
`task-N-brief.md`, carry it out following the plan's steps and the Global Constraints, record the
report as `task-N-report.md`, freeze the task's diff, have that diff reviewed independently as
`task-N-review.md`, fix and re-review when findings require it, and append one line per event to the
ledger (local scratch space, git-ignored). The ledger is
the recovery map: after any interruption, trust the ledger and `git log` over recollection, and
never redo a task it marks complete. Rulings go to the ledger as
`Ruling: <what> — <why> — <cost if wrong>`. Checkpoint pushes happen at chosen stop points; Tasks
11–13 are pushed by this checkpoint.
