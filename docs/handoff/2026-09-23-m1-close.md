# Handoff — milestone M1 closed, M2 next

## Mission

Oxidecraft is a from-scratch Rust re-implementation of the Minecraft Java Edition 1.8.9 client:
its own framing, packet codecs, world model, renderer and UI, driven by the same wire protocol the
real client speaks, with no code from RustCraft and no Mojang binaries in the repository. Version 1
is the multiplayer-first client described in `docs/specs/oxidecraft-v1-design.md`; the milestones in
its section 13 run M0 to M9, and the owner-directed post-v1 programme (singleplayer worlds, then Java
mod compatibility) is recorded in section 17.

For an acceptance run, follow the M1 procedure: start the rig server, run
`./target/debug/oxide-client --server 127.0.0.1:25565 --username <name>` for at least two minutes so
keep-alives are exercised, place a marker above y=128 and teleport the client to it through the
console FIFO, capture the window (screenshot substitute above), capture the client's own traffic with
`refs/rig/tools/record_proxy.py` and analyse it with `refs/rig/tools/analyse_capture.py`, then stop
the server, kill the client, and confirm nothing listens on 25565/25566.
