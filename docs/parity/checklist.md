# Visual parity checklist — classification

Source: `docs/research/render-parity-survey.md` section 7 (`## 7. Visual parity acceptance tests`, line 512), 57 numbered items, extracted verbatim in intent. The report's own heading assumes every item is ticked "by side-by-side screenshot"; this file applies the stricter classification required by the design specification, `docs/specs/oxidecraft-v1-design.md` appendix **C.6** (line 527): each item is exactly one of **screenshot-diffable**, **behavioural**, or **audio**, and "only the screenshot-diffable set feeds the automated image comparison".

## Classes and how each is verified

- **`screenshot`** — the item's decisive criteria can be read from still frames taken at labelled states. Verified by the capture procedure in appendix **C.2** (design spec lines 500-506): both clients placed at the same position/facing/time/weather/settings, same resolution, world frozen, then compared side by side and with a per-pixel metric. Tolerance (C.2 step 4, line 505): **no more than 2 % of pixels differing by more than 8/255 per channel, with an absolute cap of 1 % differing by more than 24/255**. This is criterion **P1** (line 88).
- **`behavioural`** — at least one decisive criterion needs a numeric measurement over time (motion, interpolation, mouse look, timing, input response, font metrics, physics feel). Verified by the numeric test vectors and timed captures of design spec section 12 (line 370, rows *Physics*, *End-to-end*, *Live*) and by criterion **P2** (line 89). These items are **not** fed to the image comparison; the still-checkable sub-criteria named in the row are still captured, but pass/fail rests on the numbers.
- **`audio`** — at least one decisive criterion needs listening or waveform comparison. Verified by a recorded audio comparison against vanilla on the rig (C.6, line 531; report section 6, lines 492-508).

Rule applied when an item mixes sub-criteria: if any named criterion cannot be decided from a still frame, the item is *not* `screenshot`. Rows note which sub-criteria remain still-checkable so the automated image-diff set can be maximised without inflating it.

`L…` citations are line numbers in `docs/research/render-parity-survey.md`; `DL…` are lines in `docs/specs/oxidecraft-v1-design.md`.
